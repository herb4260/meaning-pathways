# Data dictionary

| Variable | Meaning |
|---|---|
| `person_id` | Synthetic participant identifier |
| `facility_id` | Synthetic facility/unit identifier |
| `wave` | 1, 2, 3, or 4 |
| `months` | 0, 12, 24, 36 |
| `acute_exposure` | Critical-incident exposure index |
| `org_stress` | Chronic organizational/operational stress, 1–7 |
| `supervisor_support` | Supervisor support, 1–7 |
| `peer_support` | Peer support, 1–7 |
| `stigma` | Help-seeking stigma, 1–7 |
| `distress` | Psychological distress, 1–7 |
| `burnout` | Occupational burnout, 1–7 |
| `ptsd` | PTSD-symptom proxy, 1–7 |
| `suicidal_ideation` | Synthetic binary ideation indicator |
| `help_seeking` | Synthetic binary help-seeking indicator |
| `overtime_hours` | Administrative overtime hours |
| `sick_days` | Administrative sick-leave days |
| `critical_incidents` | Administrative incident count |
| `turnover_event` | Synthetic workforce exit event |
