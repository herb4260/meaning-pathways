# Synthetic Data Design

The data generator creates a plausible but fictional four-wave cohort. It encodes a data-generating process in which:

- greater stressor severity increases early meaning violation;
- meaning violation and meaning in life show reciprocal temporal relations;
- positive R/S coping can be mobilized by disruption and supports later meaning;
- spiritual struggle can persist alongside positive coping and predicts poorer adjustment;
- later recovery is influenced by prior recovery, meaning, meaning violation, coping, and struggle;
- monotone attrition increases across waves.

These assumptions are intentionally visible because synthetic data should not be presented as if they were discovered empirical facts. The project is a methods demonstration, not evidence for the encoded relationships.
