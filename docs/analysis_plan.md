# Analysis Plan

## Primary sequence

1. Validate ranges, IDs, monotone attrition, and synthetic-data flags.
2. Inspect missingness and wave retention.
3. Test configural, metric, and scalar longitudinal invariance for meaning and recovery items.
4. Fit a linear latent growth model for recovery.
5. Fit an RI-CLPM for meaning violation and meaning in life.
6. Fit a temporally ordered serial mediation model.
7. Fit an observed-variable moderated mediation model in which R/S struggle conditions the positive-coping → later-meaning path.
8. Summarize synthetic qualitative codes separately; do not use automated labels as final human coding.

## Fit interpretation

No single cutoff determines adequacy. Review CFI/TLI, RMSEA, SRMR, residuals, parameter plausibility, convergence, and substantive theory together. For invariance, emphasize changes in approximate fit in addition to nested tests.

## Missing data

The demo contains monotone attrition. Structural models use FIML under an MAR-style working assumption. Sensitivity analysis would be required in real data.

## Multiplicity and model flexibility

Primary paths should be preregistered in real research. Exploratory alternatives must be labeled as such.
